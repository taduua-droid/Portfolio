Local regulatory knowledge base

A private, offline tool that answers questions about clinical-research regulations and shows the source passage behind every answer — built from scratch, then stress-tested until it earned trust.

If the player doesn’t load, watch the demo on YouTube.

What
Local RAG over 6 regulations, with cited sources
Corpus
172 passages · ICH E6(R3) · 21 CFR 11/50/56/312 · 45 CFR 46
Runs on
One laptop · nothing leaves the machine · public data only
Built
August 2026

What it is, and why it’s built this way

Ask a plain-language question — “What criteria must an IRB use to approve research?” — and a language model running entirely on the laptop answers only from the retrieved regulation text, then shows that text so a human can verify it. If the answer isn’t in the loaded documents, it says so instead of guessing.

The design principle throughout: a confident, fluent, wrong regulatory answer is worse than no answer. Every choice — local hosting, grounded prompting, visible sources, an honest evaluation — serves that one idea. The tool isn’t the deliverable. The judgment about when to trust it is.

Stack

  • Ollama
  • qwen3:8b
  • nomic-embed-text
  • LlamaIndex
  • Chroma
  • pypdf
  • Streamlit

How it was built

Six phases.

  1. EnvironmentOllama + a right-sized local model, a current Python, an isolated virtual environment, LlamaIndex + Chroma.
  2. CorpusPublic regulations pulled straight from eCFR and ICH, each logged with its URL and retrieval date.
  3. IngestExtract text from the PDFs, split into passages, embed them locally, store the vectors in Chroma.
  4. Query loopRetrieve the closest passages, answer from them under a strict grounding prompt, print the sources.
  5. Verify & documentShow sources beside every answer; a README stating scope, sources, and the verify-before-trust rule.
  6. Web appA Streamlit interface so it’s a real app, not a terminal script — the version that gets demoed.
